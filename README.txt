# Nexora SaaS Website (Front-end concept)

## Run it
1. Extract this folder.
2. Open `index.html` in Chrome, or open the folder in VS Code and use the Live Server extension.
3. Internet is needed for Google Fonts. The site otherwise uses local HTML/CSS/JS.

## Pages
- `index.html` Home
- `product.html` Platform
- `solutions.html` Solutions
- `pricing.html` Pricing (illustrative prices only)
- `about.html` About
- `contact.html` Contact (demo-only form)
- `faq.html` FAQs
- `privacy.html` Privacy notice (sample)
- `terms.html` Terms (sample)

## Recent polish pass
- Scroll progress indicator and back-to-top control.
- Subtle hover lighting on feature, solution, and pricing cards.
- Monthly/yearly pricing toggle updates the illustrative prices (no checkout is connected).
- Reduced-motion preferences are respected.

## Important
This is a static front-end concept website. Forms do not send or store data. No backend, authentication, billing, or database is included.
